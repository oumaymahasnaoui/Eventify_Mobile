Une application moderne de gestion d'événements développée avec Flutter, fonctionnant à la fois sur le web et mobile avec une base de données adaptative.

## ✨ Fonctionnalités

### 🎯 Core Features
- **Inscription utilisateur** avec validation complète
- **Connexion sécurisée** 
- **Profil utilisateur** avec informations détaillées
- **Gestion des événements** (à venir)
- **Interface responsive** adaptée mobile et web

### 🛠️ Administration
- **Tableau de bord admin** complet
- **Gestion des utilisateurs**
- **Statistiques en temps réel**
- **Export des données**
- **Interface d'administration sécurisée**

### 🔄 Multiplateforme
- **📱 Mobile** : SQLite pour le stockage local
- **🌐 Web** : SharedPreferences/IndexedDB
- **Interface adaptative** selon la plateforme
